# Decision log

Append-only record of project decisions: every threshold, AOI bound, library choice, scope change, deviation from [`ROADMAP.md`](ROADMAP.md) and resolved open question. Split out of ROADMAP §11 on 2026-11-20 (entry #29) because it will keep growing.

## How to add an entry

- **Append** a row at the bottom with the next number. Never edit or delete earlier rows. If a decision is reversed, add a new row that says which entry it supersedes (e.g. "Supersedes #14").
- **Columns:** `#` · `Date` (YYYY-MM-DD) · `Decision` (what was decided, with the concrete values) · `Rationale` (why, including evidence or the source link) · `Made by` (task ID, and "project owner" when a person decided) · `Affects` (tasks, files or roadmap sections).
- Section references such as "§3.4" point to [`ROADMAP.md`](ROADMAP.md). Elsewhere, cite entries as "Decision log #N" (`docs/DECISIONS.md`).
- A resolved item from ROADMAP §12 (Open questions) gets a row here, and the question is marked resolved there with the entry number.
